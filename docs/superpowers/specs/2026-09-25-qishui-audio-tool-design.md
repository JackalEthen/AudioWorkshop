# 汽水音乐个人音频工具设计规格

**状态**：已确认，作为实现基线  
**日期**：2026-09-25  
**平台**：Android 原生  
**原型**：`.superpowers/brainstorm/opencode-1790328597/content/layout-v3-light-palette.html`

## 1. 产品目标

为个人日常使用提供一个 Android 工具：输入汽水音乐分享文本或链接，解析可获得的歌曲信息、音频和逐字歌词；将歌曲或本地 MP3、WAV、FLAC 导入非破坏式编辑器；最终导出一个同时包含音频、歌曲信息、封面和歌词的 MP3 文件。

应用不运营、不共享、不提供公开服务，也不实现绕过 DRM、会员、地区、风控或下载限制的逻辑。

## 2. 已锁定决策

| 决策 | 结论 |
|---|---|
| 使用范围 | 纯个人使用 |
| 平台 | Android 原生，最低 Android 8.0/API 26，目标 Android 16/API 36 |
| UI | Kotlin + Jetpack Compose + Material 3，浅色、高饱和点缀、圆角悬浮卡片 |
| 跨平台 | 不采用 Flutter、React Native、Compose Multiplatform |
| 解析方式 | Android 客户端直接调用用户现有 API |
| API 输入 | 分享文本或链接；分享文本允许包含链接和附加文案 |
| API 样例 | 临时签名 M4A/AAC 音频直链、逐字时间轴歌词、歌手和专辑信息 |
| 本地导入 | MP3、WAV、FLAC，首版仅支持单声道/双声道的常见格式 |
| API 导入 | 样例中的 M4A/AAC |
| 编辑 | 裁剪、分割、拼接、淡入淡出、增益、歌词时间校正 |
| 分割语义 | 同时支持“保留选中部分”和“删除选中部分” |
| 编辑方式 | 非破坏式；源文件永不覆盖 |
| 导出 | 只输出一个 MP3 文件，不输出旁车歌词文件 |
| 单文件内容 | 音频、标题、歌手、专辑、封面、USLT 文本歌词、SYLT 同步歌词 |
| 外部播放器 | 不承诺逐字歌词显示；本应用必须能完整重导入自己的导出文件 |
| 下载 | 应用前台执行；退出后不继续；再次打开可断点续传 |
| 下载管理 | 暂停、继续、重试、删除；删除时可分别选择删除记录和删除文件 |
| 进度提示 | 不使用通知栏下载进度 |
| 设置 | 外观、下载、其他、关于四个可进入页面 |
| 外观 | 壁纸、5 套浅色主题、字体大小、壁纸透明度/模糊度、卡片透明度/模糊度 |
| 下载设置 | 下载目录、下载连接数 |
| 其他设置 | 自动命名正则表达式 |
| 命名默认值 | `{歌名}-{歌手}` |
| 本地工具链 | 全部使用 `T:\Android`，不另下载 Gradle |

## 3. 范围

### 3.1 MVP 包含

- 解析 API 配置与直接调用。
- 分享文本、URL、剪贴板读取和错误状态。
- 解析等待动画与分字段结果展示。
- 音频下载、断点续传、暂停、继续、重试、校验和下载中心。
- 本地 MP3、WAV、FLAC 导入。
- 音频预览、波形、时间轴、选区和两类分割逻辑。
- 裁剪、分割、拼接、淡入淡出、增益、歌词校正。
- 每个编辑功能的分类历史记录。
- 单文件 MP3 导出与标签、封面、歌词写入。
- 导出文件回读、解码、时长、标签和歌词校验。
- 浅色 Material 3 界面和 5 套主题。
- 外观、下载、其他、关于设置页面。

### 3.2 MVP 不包含

- 后台下载服务和通知栏进度。
- 云同步、账号、多设备历史同步。
- 多轨混音、频谱编辑、变速、变调、混音台。
- 外部播放器逐字歌词兼容保证。
- DRM、验证码、会员、地区、设备风控或签名逆向。
- 复杂 WAV、24/32-bit 浮点 WAV、特殊 FLAC、多声道等高级输入兼容。
- 公开分发、商业化和运营能力。

## 4. 页面与导航

应用采用单 Activity 和底部三导航。

### 4.1 解析页

- 顶部标题“解析”，右上角三横菜单。
- 输入卡片：分享文本输入框、读取剪贴板、开始解析。
- 等待状态：动态均衡器动画，展示当前阶段和可取消操作。
- 结果卡片分字段展示：歌名、歌手、专辑、时长、格式、编码、码率、采样率、文件大小、歌词状态、歌词预览。
- 操作：试听、下载歌曲、进入编辑。
- 右上角菜单进入记录中心。

### 4.2 记录中心

采用一个页面，顶部两个标签：

- 解析历史。
- 下载中心。

下载记录支持：

- 等待、下载中、暂停、失败、完成、已取消状态。
- 进度、已下载大小、总大小、速度、错误原因。
- 暂停、继续、重试、打开文件、重新下载。
- 删除弹层包含“删除记录”和“删除文件”两个复选框；两项均未选择时确认按钮不可用。
- 删除文件时同时清理对应临时文件和最终文件。
- 解析历史可重新载入结果，不自动重复下载。

### 4.3 编辑页

- 顶部标题“编辑”，右上角“记录”。
- 无 Banner。
- 双栏大字号功能卡片，不使用图标。
- 功能：裁剪、分割、拼接、淡入淡出、音量增益、歌词校正。
- 记录页顶部按功能分类，显示使用该功能后的歌曲和编辑项目。
- 功能编辑器使用波形和时间轴作为主视觉。

### 4.4 设置首页

四个圆角入口卡片：

1. 外观
2. 下载
3. 其他
4. 关于

### 4.5 外观设置

- 主体配色：元气橙、晴空蓝、薄荷青、星云紫、桃桃粉。
- 字体大小：小、标准、大、特大。
- 主界面壁纸：系统选择器导入外部图片。
- 壁纸透明度。
- 壁纸模糊度。
- 卡片透明度。
- 卡片模糊度。
- 所有修改即时预览并持久化。

### 4.6 下载设置

- 下载目录：SAF 选择并持久化权限。
- 下载连接数：首版支持 1–4，默认 3。
- 下载目录不可用时明确提示，不静默回退到不可预测位置。

### 4.7 其他设置

- 自动命名格式：正则表达式或模板变量输入。
- 默认 `{歌名}-{歌手}`。
- 提供文件名预览和合法性校验。
- 禁止路径分隔符、控制字符和系统保留名称。

### 4.8 关于

- 应用版本。
- API 配置状态。
- 开源许可证。
- 本地工具和媒体处理能力说明。

## 5. 视觉系统

### 5.1 原则

- 全部主题使用纯白或近白背景，不提供暗色主题。
- 高饱和色只用于主要操作、选区、进度和状态，不作为大面积暗色背景。
- 卡片使用 16–20dp 圆角、轻阴影和可选透明度/模糊度。
- 功能卡只使用醒目的大字号和一句说明，不使用图标。
- 触控目标不小于 48dp。
- 使用 Material 3 类型层级和系统返回行为。
- 动画只表达状态变化，遵循系统“移除动画”设置。

### 5.2 五套主题

- Background：纯白 `oklch(100% 0 0)`。

## 6. 领域模型

核心对象：

- `SourceTrack`：不可变源音频描述。
- `TrackMetadata`：标题、歌手、专辑、封面、时长和格式信息。
- `LyricsTrack`：歌词行、逐字时间、语言和 offset。
- `EditProject`：源曲目引用、功能历史和当前编辑参数。
- `EditSegment`：保留区间及其源时间、输出时间。
- `EditMode`：`KEEP_SELECTED` 或 `REMOVE_SELECTED`。
- `DownloadTask`：URL、临时文件、进度、校验信息和状态。
- `ParseRecord`：解析结果摘要和错误信息。
- `ExportPackage`：最终 MP3、校验结果和来源关系。

关系：

```text
Share Input
  → Resolution
  → SourceTrack
      ├→ DownloadTask
      └→ EditProject
          └→ ExportPackage
```

## 7. API 边界

### 7.1 已知响应形状

样例响应包含：

- 顶层：`code`、`msg`、`data`。
- 音频 URL：`data.url`，为临时签名地址。
- 音频信息：`data.video_meta`。
  - `quality`
  - `vtype`
  - `bitrate`
  - `codec_type`
  - `size`
  - `file_id`
  - `file_hash`
  - `real_bitrate`
  - `audio_sample_rate`
- 逐字歌词：`data.lyric`。
- 专辑：`albumname`。
- 歌手：`artistsid`、`artistsname`、头像 URL 列表。
- 业务信息：`cache_status`、`bktip`。

逐字歌词格式：

```text
[行开始毫秒,行持续毫秒]<相对毫秒,持续毫秒,标记>字<相对毫秒,持续毫秒,标记>字
```

示例：

```text
[18034,3519]<0,331,0>我<440,331,0>站<880,331,0>在
```

### 7.2 API 适配器

- UI 和领域层只使用规范化模型，不直接依赖 API 字段。
- 单独适配器负责请求、状态码、字段空值、歌词解析和错误映射。
- API 端点为 `GET https://api.bugpk.com/api/qsmusic?url={分享链接}`，公开调用无需 key，站点标注 QPS=1。
- 响应顶层 `cache_expire_at` 是临时 URL 缓存过期时间；客户端不自行推算。
- `video_meta.file_hash` 已用真实文件验证为 32 位十六进制 MD5。
- URL、歌词和封面都视为不可信输入。
- 不记录完整签名 URL、鉴权头或账号凭据。
- API 失败时不做网页抓取回退。

## 8. 下载与校验

- 使用 OkHttp。
- 下载写入 `.part` 文件。
- 续传使用 `Range`、`If-Range`、`ETag` 或 `Last-Modified`。
- 只有合法的 `206` 和匹配的 `Content-Range` 才追加。
- 服务端返回 `200` 时清空临时文件并重新下载。
- `403`、`410`、签名失效时允许重新调用解析 API 获取新地址，但必须由用户确认或自动策略明确记录。
- 下载后按顺序校验：HTTP 状态、Content-Type、容器魔数、声明大小、哈希算法、完整解码、时长和音轨。
- `file_hash` 按 MD5 校验；字段缺失时不猜测，降级为长度、容器和完整解码校验，并在记录中标注验证级别。
- 校验成功后原子重命名为最终文件。

## 9. 音频编辑

### 9.1 输入范围

首版接受：

- API 返回的 M4A/AAC。
- 本地 MP3。
- 8/16-bit PCM WAV。
- 16/24-bit FLAC。
- 单声道或双声道。
- 44.1 kHz 或 48 kHz。

API 26 的 FLAC 解码缺口由 NDK 版 libFLAC 补齐。其他复杂编码首版明确拒绝，不静默转换。

### 9.2 编辑语义

- 所有编辑保存为 Edit Project，不修改 SourceTrack。
- `KEEP_SELECTED`：选中区间按源顺序保留并拼接。
- `REMOVE_SELECTED`：选中区间删除，剩余区间按源顺序拼接。
- 裁剪调整源时间和输出时间。
- 分割只建立边界，不复制音频。
- 拼接累加每段输出起点。
- 增益和淡化不改变歌词时间。
- 歌词时间根据保留区间变换，删除区间内的歌词事件同时删除。
- 预览和导出复用同一套时间映射。

### 9.3 波形

- 首次探测时流式生成多分辨率 min/max/RMS 峰值。
- UI 只接收峰值包络，不接收完整 PCM。
- Compose Canvas 绘制视口范围；手势层只更新选区覆盖层。
- 如 Canvas 真机性能不足，仅嵌入自定义 SurfaceView，不更换整个 UI 框架。

## 10. MP3 导出

### 10.1 编码

- Media3 ExoPlayer 负责播放。
- 平台解码器和 libFLAC 负责输入解码。
- PCM 流经过裁剪、拼接、增益和淡化。
- NDK 独立编码进程调用 `libmp3lame` 输出 MP3。
- 默认使用 VBR V2；保留 44.1/48 kHz 和源声道数。
- 多声道或不支持的采样率明确拒绝。
- 原生崩溃不带走主进程；编码任务可整体重试。

### 10.2 ID3v2.4

最终文件写入：

- `TIT2`：标题。
- `TPE1`：歌手。
- `TALB`：专辑。
- `TDRC`：日期或年份。
- `APIC`：封面。
- `USLT`：完整文本歌词降级。
- `SYLT`：行级或逐字同步歌词。

约束：

- 文本帧使用 UTF-16 with BOM。
- 中文语言统一为 `zho`。
- ID3v2.4 长度字段使用 synchsafe 整数；SYLT 时间戳使用普通 32 位大端毫秒。
- 不使用扩展头、footer、压缩、加密或分组。
- 应用自行实现受限读写器，只处理约定帧；未知帧安全跳过。
- 导出后回读标签和歌词，并完整解码一次。

### 10.3 外部兼容边界

- 音频、标题、歌手、专辑和封面按标准 ID3 写入。
- `USLT` 提供不支持同步歌词播放器的文本降级。
- `SYLT` 支持度由外部播放器决定，不承诺所有播放器逐字显示。
- 本应用重导入自己的文件必须完整恢复 Metadata、封面和歌词时间轴。

## 11. 状态与错误

主要状态：

```text
IDLE
→ RESOLVING
→ DOWNLOADING ⇄ PAUSED
→ VERIFYING_DOWNLOAD
→ PROBING
→ READY
→ EDITING / PREVIEWING
→ EXPORTING
→ COMPLETED
```

任意活动状态可进入 `FAILED` 或 `CANCELED`。

错误分类：

- 输入为空或不是支持的分享链接。
- API 超时、网络失败、限流、鉴权失败。
- 解析成功但无音频或无歌词。
- 临时音频 URL 失效。
- 下载校验失败。
- 不支持的输入编码、采样率或声道。
- 存储空间不足或用户取消保存。
- MP3 编码或 ID3 写入失败。
- 导出回读验证失败。

界面必须显示用户可理解的错误和恢复动作，不暴露密钥、完整签名 URL 或底层堆栈。

## 12. 技术架构

- 单 Activity。
- 单 `app` 模块。
- MVVM/UDF。
- ViewModel + StateFlow。
- Coroutines + Flow。
- 手动依赖注入，通过 Application 级容器创建共享对象。
- 不使用 Hilt。
- Navigation Compose 管理三个底部入口和功能子页面。
- Room 保存 Parse Record、Download Task、Edit Project 和历史。
- DataStore Preferences 保存设置。
- SAF + MediaStore 管理用户可见文件。
- 原生编码置于独立 `:encoder` 边界；首版可先使用同模块的隔离 Service，不提前拆 Gradle module。

高内聚、低耦合约束：

- `domain/model` 只保存稳定业务模型和窄接口，不依赖 Android、Compose、OkHttp 或 `org.json`。
- `data/api` 只负责外部协议、JSON 映射、网络错误和向领域模型转换，不包含页面状态或业务编辑逻辑。
- `feature/*` 的 ViewModel 依赖 `domain` 中的窄接口，不直接依赖具体 HTTP 客户端或数据库实现。
- UI 只消费不可变 UI State 和用户事件，不直接读取网络、磁盘或其他模块内部状态。
- Navigation、下载、歌词、音频处理和设置分别封装；禁止跨 feature 调用内部 Composable 或可变单例。
- 依赖方向固定为 `feature → domain ← data`；`app` 负责组装实现，不允许反向依赖。
- 单个文件只承担一个明确职责；出现跨功能共享状态时先提升为稳定领域模型或窄接口，不创建 God Object。
- 仅在存在真实替换边界、测试替身或跨实现需求时定义接口，不为形式主义增加抽象。

## 14. 安全与隐私

- 只保存完成任务所需的数据。
- 不保存账号密码、Cookie 或长期会话凭据。
- 临时 URL、鉴权头和歌词原文不得写入普通日志。
- 下载域名、重定向和文件大小设置边界。
- 文件名经过清理，不允许路径穿越。
- 临时文件与最终文件分离。
- 最终文件只有在全部验证通过后发布。
- API 密钥或接口配置只保存在用户明确配置的位置。

## 15. MVP 验收

1. Android 8.0 和 Android 16 设备可安装启动。
2. 三个底部导航和四个设置入口符合已确认原型。
3. 五套主题可即时切换并持久化。
4. 导入 MP3、WAV、FLAC 和 API M4A 后可预览并生成波形。
5. 保留选中和删除选中均产生正确音频时间线。
6. 裁剪、分割、拼接、淡入淡出、增益和歌词校正历史可分类查看。
7. 下载暂停后可续传；删除记录和删除文件相互独立。
8. 导出的最终目录只新增一个 MP3。
9. MP3 包含标题、歌手、专辑、封面、USLT 和 SYLT。
10. 本应用可重导入导出文件并恢复歌词时间轴。
11. 无效 URL、无歌词、URL 过期、校验失败和编码失败均有明确恢复动作。
12. 连续导出不会覆盖源文件或丢失编辑项目。

## 16. 外部依赖

解析接口已确认：

- 请求方式和参数：`GET /api/qsmusic?url={分享链接}`。
- 无需 key，站点标注 QPS=1。
- 成功与失败响应已有样例。
- 临时 URL 使用顶层 `cache_expire_at`。
- `file_hash` 已验证为 MD5。

仍需通过更多真实样本确认：

- 歌词自定义语法的空行、纯音乐、多语言和三列时间标记边界。
- `artistsmedium_avatar_url` 是否始终可用；它不是歌曲封面。
- 失效链接、地区限制和上游异常返回码集合。

这些未知项不阻塞下载与基础编辑，但阻塞歌词解析器的最终异常矩阵。
